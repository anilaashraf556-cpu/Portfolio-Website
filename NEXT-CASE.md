### 1. Problem

Explain the disaster evacuation problem the project is designed to solve and why helping people find suitable shelters is important.

Explain what I built, the technologies I used, how the recommendation system works, and the main features I implemented.

2. Add the project to the portfolio's **Projects** section.
3. Write the case study using **Problem → What I Did → What Came of It**.

5. Test the case study and project on desktop and mobile.
6. Check that all links and features work correctly.
7. Commit the changes to GitHub.
8. Redeploy the updated portfolio.
