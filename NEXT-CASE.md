# Next Case Study Plan

## Next Project

**AI Disaster Evacuation & Shelter Recommendation System**

This will be the next real project I plan to add as a case study to my portfolio.

## How I Will Add the Next Case Study

When the project is ready, I will add it to the **Projects** section of my portfolio and create a case study using the same three-part structure:

### 1. Problem

Explain the disaster evacuation problem the project is designed to solve and why helping people find suitable shelters is important.

### 2. What I Did

Explain what I built, the technologies I used, how the recommendation system works, and the main features I implemented.

### 3. What Came of It

Explain the final result, including the working features, screenshots, live demo, GitHub repository, and what I learned from building the project.

## Steps to Add the Case Study

1. Complete the project and make sure the main features work.
2. Add the project to the portfolio's **Projects** section.
3. Write the case study using **Problem → What I Did → What Came of It**.
4. Add relevant screenshots and project links.
5. Test the case study and project on desktop and mobile.
6. Check that all links and features work correctly.
7. Commit the changes to GitHub.
8. Redeploy the updated portfolio.

## Build Context

I will continue using my existing **Claude Project** for future portfolio updates so that my portfolio's voice, technology stack, and identity context are preserved.
